# rpkit

A self-hostable relying-party implementation for [World ID](https://docs.world.org/world-id).

rpkit lets an application request World ID proofs, verify every proof type, enforce nonce and nullifier uniqueness, and pay protocol fees, all on its own infrastructure.

**Status:** design phase. See the [specification](docs/spec.md).
